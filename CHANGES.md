# Changes to the files you were given

List anything you changed in the files that were in this repository when you started (for example in `/database`), and why.

| File                           | What I changed                                                                    | Why                                                                                                                                                                                                                                  |
| ------------------------------ | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `schema.sql` (S1)              | Changed `contacts.can_view_records` default from `1` to `0`.                      | A default of 1 gave unauthorized contacts access to sensitive data automatically, violating POPIA.                                                                                                                                   |
| `seed.sql` (S2)                | Removed `UPDATE learners SET data_mode = 'low' WHERE district IN...`              | Unfair geographic profiling. Limits a learner's access to information based on location, which is biased.                                                                                                                            |
| `schema.sql` & `seed.sql` (S3) | Removed the `id_number` column entirely.                                          | Reslocate is a pathway service; storing full SA ID numbers violates data minimization rules and poses a massive security risk.                                                                                                       |
| `queries.sql` (C1)             | Changed query 3 from `LIKE '%approved%'` to `lower(trim(f.status)) = 'approved'`. | `LIKE` accidentally includes "Provisionally approved", which falsely tells the system a pending learner is fully funded.                                                                                                             |
| `seed.sql` (C2)                | Set `expected_payment_date` to `NULL` for Ayanda.                                 | NSFAS never sets a payment date if `registration_confirmed = 0`. The database was lying, which could cause the AI to guarantee false dates.                                                                                          |
| `schema.sql` (C3)              | Changed `allowance_paid` default from `1` to `0`.                                 | Defaulting to 1 falsely tells the system unverified learners have already received cash.                                                                                                                                             |
| `README.md` (W1 & W2)          | Changed Goal 1 & 2 back to their original state                                   | Being "as helpful as possible" forces the AI to hallucinate or guess dangerous answers to please the user. Reslocate's database tracks state, but relying on it for legally binding financial decisions (like a lease) is dangerous. |
| `/database/reslocate_mock.db`  | Rebuilt the database using the bash commands                                      | To ensure the application's database reflects the S1-S3 and C1-C3 safety fixes.                                                                                                                                                      |
